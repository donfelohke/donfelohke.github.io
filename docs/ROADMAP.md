# Roadmap

This is a plan, not a completion claim.

## Phase 0 — Establish site
- [ ] Review and merge homepage/documentation.
- [ ] Enable Pages with GitHub Actions.
- [ ] Confirm HTML checks, mobile/keyboard behaviour and live URL.

## Phase 1 — Stabilise portfolio
- [ ] Verify prices, contact details and location phrase with the owner.
- [ ] Add only real screenshots and project artefacts.
- [ ] Review contrast, focus, headings, links and reduced motion.
- [ ] Maintain release notes and publishing checklist.

## Phase 2 — Document ecosystem
- [ ] Create project records for WARENA, IKAI, GENJE and the FELOH corpus.
- [ ] Record purpose, stage, stewards, architecture, risks, tests, evidence and next decision.
- [ ] Link canonical source repositories only after verifying URLs.

## Phase 3 — Stewardship
- [ ] Use PRs for substantive changes.
- [ ] Require a passing status check and protect main where available.
- [ ] Establish backup maintainer and periodic access review.
- [ ] Test recovery and publishing procedures.

Acceptance requires an artefact or setting, passing checks and evidence such as a commit, PR, workflow run or Pages status.
