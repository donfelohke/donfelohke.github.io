# Brand canon

- GRACE — The Crown / NAKEBUSEN: Your Crown. Your Craft. Loc care, craft, livelihood, dignity and direct customer contact.
- GRIT — The Code / WARENA: Freedom Is a System. Sovereign, inspectable, reproducible and maintainable computing.
- GLORY — The Craft / FELOH / @donfelohke: Live the Code. Embody the Expression. Human authorship and expression.
- IKAI — Mirror / Reflect: a mirror, not a judge; no identity capture, diagnosis or scoring.
- GENJE — Wave / Embody: AfroTech, Genge, live coding, movement and choreohacking.

Governing formula: FELOH generates. NAKEBUSEN grounds. IKAI reflects. WARENA enables. GENJE embodies.

NAKEBUSEN is the customer-facing service domain; WARENA powers technical systems; GENJE ZA WARENA connects creative performance and technology; IKAI remains work in progress unless a specific artefact is evidenced. DonFeloh remains the human author. Only NAKEBUSEN transacts.

Visual direction: editorial/documentary/terminal/archive, not generic SaaS. Core palette #111111, #F2EFEA, #D4AF37; optional accents #E2725B and #033500; reserve #79D7D2 for IKAI contexts. Prioritise legibility and meaningful artefacts over clutter or neon haze.
