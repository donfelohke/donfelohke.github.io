## Publication controls

1. A repository is not automatically a publication.
2. A research dossier, creative-practice record and source repository must be labelled distinctly.
3. Website entries require an accurate title, type/status, date where known, short description and canonical destination.
4. Publish authored essays or reflections only when actual approved source material exists; do not create placeholder entries.
5. Mark research and work-in-progress material explicitly.
6. Update this register when adding, correcting or retiring a public entry.
