## Publication decision meanings

- **YES:** an approved, bounded summary or link may appear on the named public page. It does not imply the underlying research is validated or deployed.
- **NO:** retain as an internal editorial/governance record or contextual source; do not create a standalone public entry.
- **DEFERRED:** wait for a curated record, evidence review or explicit editorial decision.
- **LIVE / PUBLIC:** only for an existing public service or page whose current state is supported by the canonical records.

**Publication control:** Every YES entry must show its maturity accurately, link to its canonical source and preserve the distinction between research, proposed experiments, implementation and validation. The website must not auto-publish repository content.
