## Positioning

**Freedom Is a System.**  
Practical technology for people and organisations that need systems they can understand, maintain and adapt — including when connectivity is unreliable.

Not: generic “AI product” catalogue · cloud-only dependency theatre · unsupported uptime SLAs.

3. **Networks** — Wi-Fi, LAN, router configuration  
4. **Infrastructure** — small-office servers, shared services  
5. **Learning spaces** — laboratory, classroom, cybercafé setups  
6. **Local-first** — offline-capable environments where appropriate  
7. **Development** — reproducible toolchains and systems engineering practice

## Enquiry script (WhatsApp / email)

> Hello NAKEBUSEN / WARENA — I would like to discuss a technology project.

Ask the client for: current setup · problem · desired outcome · location · timeline · constraints (budget, offline, multi-user).

**Reply principle:** Scope, feasibility, deliverables, pricing and support are agreed **before** work begins. An enquiry is not an accepted project.

---

## Proposal structure (tech)

1. Context (what exists)  
2. Problem  
3. Proposed work  
4. Deliverables  
5. Assumptions and limits  
6. Price / payment terms  
7. Support window (if any)  

Label maturity: **LIVE** (you operate this today) vs **PROPOSAL** vs **RESEARCH** (e.g. IKAI).

---

## Forbidden claims

- IKAI as shipped product  
- Guaranteed uptime without contract evidence  
- “Enterprise” scale without capacity  
- Client names without permission  
- Security guarantees beyond stated practice
