## Publication implementation

- One hand-authored `index.html` and static CSS.
- Minimal inline JavaScript only for independent English / Kiswahili and light / dark toggles.
- English is the default when JavaScript is unavailable; CSS follows the system colour preference until the theme is explicitly changed.
- Native anchor navigation, semantic landmarks, keyboard focus, responsive layout, reduced-motion and reduced-transparency support.
- No framework, package manager, CMS, analytics, tracking, remote fonts, CDNs or third-party runtime.
- No new repository or domain. Existing GPL-3.0 license is preserved.

Run dependency-free source checks with: `python -m unittest discover -s tests -v`

Source tests are a gate, not a substitute for keyboard, screen-reader, device, browser and live Pages verification. Do not invent prices, testimonials, credentials, customer details, capabilities or deployment claims.
