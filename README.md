## Implementation

- One hand-authored `index.html` and one primary stylesheet, `assets/css/site.css`.
- Native HTML and CSS; no JavaScript runtime, framework, package manager, CMS, analytics, tracking, remote fonts, CDN or third-party runtime.
- System light/dark preference; reduced-motion and reduced-transparency support.
- Semantic landmarks, visible keyboard focus, skip link, responsive layouts and safe-area-aware navigation.
- English is the default. Kiswahili content is authored with language attributes and switched using native CSS controls.

Run source checks: `python -m unittest discover -s tests -v`

Source checks do not replace manual browser, keyboard, screen-reader and live Pages verification.
