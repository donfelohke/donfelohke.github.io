## Website principles

- Static HTML and progressive enhancement; text-first, not text-only.
- No required CDN fonts, analytics or tracking pixels.
- English default; publish Kiswahili as reviewed only after human review and control testing.
- Use genuine campaign imagery only after Gallery provenance, rights, consent and approval checks.
