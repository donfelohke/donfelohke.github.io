# Security policy

This is a static portfolio and documentation repository. It should not collect credentials or customer records.

Do not publish exploitable details or secrets in public issues. Contact the owner privately through a trusted channel available from the GitHub profile. Include affected file/URL, impact and safe reproduction steps; never include customer data.

Never commit passwords, API keys, OAuth tokens, private keys or session cookies. If a secret is committed, revoke/rotate it immediately; deleting the latest copy is not enough. Use Actions secrets only when genuinely required. Static Pages deployment should not need deployment tokens. Review third-party actions before adding automation.
