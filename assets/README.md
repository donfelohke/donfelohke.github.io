# Website visual assets

The repository currently contains no approved client/service photographs or approved technical/creative portfolio images. Do not portray stock or generated images as real customer work.

When adding visuals, use owner-approved, permission-cleared files:
- Loc-care hero or service photographs: real work, accurate context, no identifying client details without explicit consent.
- Technical work: genuine device, network, workstation or reproducible-build artefacts.
- GENJE: approved performance, movement or live-coding photographs.
- Social preview: composed from approved imagery and brand typography.

Suggested delivery: optimized WebP/JPEG for photographs, descriptive filenames, responsive sizing, and meaningful alt text. Avoid uploading sensitive customer data or private device/network details. Keep decorative assets empty-alt when they convey no information.
