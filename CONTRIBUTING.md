# Contributing

Read README.md, AGENTS.md, GOVERNANCE.md and relevant docs. Also read [AI-Assisted Changes and Website Source Provenance](AI-ASSISTED-DEVELOPMENT.md). Create a descriptive branch, keep changes focused, explain the need and acceptance criteria, run checks, and open a pull request with evidence and limitations. Review visual changes on mobile and desktop. Do not invent facts, testimonials, service guarantees, prices or deployment status. Keep the site accessible and dependency-light. Never commit secrets or private customer data. Never submit customer-confidential data or unauthorised source material to external AI tools. Disclose material AI assistance in substantive code or public copy. Preserve the existing GPL-3.0 LICENSE; it does not grant rights to third-party or Gallery assets.
